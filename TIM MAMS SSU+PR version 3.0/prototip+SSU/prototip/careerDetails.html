Frontend Developer

Opis zanimanja

Frontend developer razvija korisnički interfejs web aplikacija koristeći tehnologije kao što su HTML, CSS i JavaScript. Njegov zadatak je da aplikacija bude vizuelno privlačna i funkcionalna za krajnjeg korisnika.

Potrebne veštine
  • HTML, CSS, JavaScript
  • Rad sa framework-ovima (React, Angular)
  • Osnove UX/UI dizajna
  • Git i verzionisanje koda
Moguće pozicije
  • Frontend Intern
  • Junior Frontend Developer
  • Frontend Developer
